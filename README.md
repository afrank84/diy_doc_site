# diy_doc_site
trying to simplify stuff.

```graphhql
/my-repo
│
├── .github
│   └── workflows
│       └── md-to-html.yml          # GitHub Actions workflow file
│
├── docs                            # Folder containing all Markdown files
│   ├── file1.md                    # Example Markdown file
│   ├── file2.md                    # Another Markdown file
│   └── subfolder                   # Optional subfolder for organizing Markdown
│       └── nested.md               # Nested Markdown file
│
├── static                          # Folder for generated HTML files
│   ├── file1.html                  # Generated HTML file for file1.md
│   ├── file2.html                  # Generated HTML file for file2.md
│   └── subfolder                   # Optional subfolder to match docs structure
│       └── nested.html             # Generated HTML file for nested.md
└── template.html                   # HTML template with placeholder
```
